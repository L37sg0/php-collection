# Laravel Projects Workspace

This directory contains a collection of diverse Laravel applications, ranging from feature platforms to early architectural concepts and database schemas.
---
## Project List

1. **`blog`** – A classic blogging platform with posts, comments, and a public user interface.
2. **`carwash-website`** – A presentation website and booking platform for a car wash service.
3. **`cv-app`** – An application for creating, managing, and generating professional resumes and CVs.
4. **`ecommerce-hub`** – An e-commerce platform featuring a product catalog, shopping cart, and order management.
5. **`job-board`** – A job board platform connecting employers with job seekers.
6. **`library-cms`** – A content management system (CMS) specialized for libraries (book catalogs, authors, and inventory).
7. **`news-cms`** – A CMS for news sites and media outlets with categories, articles, and an editorial dashboard.
8. **`pictures-cms`** – A photo portfolio and CMS designed for managing image galleries.
9. **`rockstar`** – A modular web application for a fictional rock band, featuring a public frontend and an admin dashboard.
10. **`ticket`** – A backend API for a helpdesk and ticketing system equipped with robust request validation.
11. **`windpark-dashboard`** – An early monitoring and management system for wind farms, turbines, and electrical infrastructure.
12. **`wms`** – An architectural database concept for a Warehouse Management System (WMS) featuring inventory tracking, order fulfillment, and RBAC permissions.
