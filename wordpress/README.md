# WordPress Development Portfolio

A collection of custom-built WordPress themes, plugins, widgets, and utility extensions created to explore WordPress architecture, modern frontend frameworks, and custom functionality.

---

## Directory Structure & Components

```text
wordpress/
├── abc-plugin/             # Custom utility or feature plugin
├── bs5-blocks/             # Bootstrap 5 custom Gutenberg blocks package
├── greeting-widget/        # Custom interactive greeting widget
├── shortcodes-plugin/      # Custom shortcodes implementation for content extension
├── text-correction-plugin/ # Automated or utility text correction plugin
├── text-widget/            # Custom text widget block/extension
├── theme1/                 # Initial custom WordPress theme integrated with Bootstrap 5 and Navwalker
├── theme-l37sg0/           # Personalized custom theme implementation
├── turbines-plugin/        # Object-oriented machine planning plugin for wind parks (Turbines)
└── README.md               # Portfolio overview documentation

```

---

## Featured Components Breakdown

### Themes

* **`theme1`**: A foundational custom theme leveraging Bootstrap 5, FontAwesome, and the WP Bootstrap Navwalker for responsive layouts and advanced menu management.
* **`theme-l37sg0`**: A personalized custom theme tailored for dedicated portfolio and layout requirements.
---
### Plugins & Widgets

* **`turbines-plugin` (Турбини):** An advanced, modular object-oriented plugin built following Alessandro Castellani's architecture tutorials, designed for wind park machine planning with custom post types, settings APIs, and PSR-4 autoloading.
* **`bs5-blocks`**: Custom block development incorporating Bootstrap 5 design systems directly into the WordPress block editor.
* **Utility Plugins (`abc-plugin`, `shortcodes-plugin`, `text-correction-plugin`)**: Modular additions expanding core site functionality with custom shortcodes and text manipulation features.
* **Widgets (`greeting-widget`, `text-widget`)**: Custom widget implementations providing dynamic sidebar and content block options.
